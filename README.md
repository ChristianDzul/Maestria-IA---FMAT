# Maestria-IA---FMAT

Repositorio generado para llevar registro de actividades, proyectos y documentación para la maestría de Inteligencia Artificial.

## Estructura del repositorio

- `actividades/`: Registro de tareas, ejercicios y avances semanales.
- `proyectos/`: Desarrollo y entregables de proyectos.
- `documentos/`: Apuntes, lecturas y material de referencia.
