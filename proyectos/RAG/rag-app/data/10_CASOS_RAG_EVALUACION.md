# Dataset de Preguntas para Evaluación RAG

**Clasificación:** SINTÉTICO

## Preguntas conceptuales
1. ¿Qué funciones cumple un Command Center?
2. ¿Qué diferencia existe entre Front, Middle y Back Office?
3. ¿Qué es una conciliación?
4. ¿Qué significa P1?
5. ¿Qué elementos debe contener un incidente?

## Preguntas de recuperación
6. ¿Cuándo se activa el Command Center?
7. ¿Cuándo debe escalarse un incidente P2?
8. ¿Qué información debe obtenerse para investigar una transferencia?
9. ¿Qué áreas intervienen ante una diferencia de conciliación?
10. ¿Quién coordina un incidente mayor?

## Preguntas multi-documento
11. Una transferencia está pendiente y afecta a miles de clientes. ¿Qué procedimiento debe seguirse y cuándo se activa Command Center?
12. Una aplicación está disponible pero las operaciones no se reflejan en el ledger. ¿Es suficiente con declarar recuperado el servicio?
13. Un proveedor externo está caído y afecta un proceso crítico. ¿Qué acciones y escalaciones aplican?
14. Existe confirmación externa de pago pero el core no muestra el movimiento. ¿Qué áreas deben participar?
15. Un incidente inicialmente P3 aumenta rápidamente a miles de clientes. ¿Cómo debe cambiar la gestión?

## Respuesta esperada del RAG
Una respuesta de calidad debe:
- citar los documentos recuperados;
- distinguir política pública de procedimiento sintético;
- identificar área responsable;
- indicar severidad;
- indicar SLA/OLA;
- explicar escalaciones;
- evitar inventar datos no presentes;
- señalar incertidumbre cuando corresponda.
