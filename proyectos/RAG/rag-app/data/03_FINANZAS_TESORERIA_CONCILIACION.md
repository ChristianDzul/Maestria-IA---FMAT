# Finanzas, Tesorería y Conciliaciones

**Clasificación:** SINTÉTICO

## 1. Finanzas

Responsabilidades simuladas:
- Contabilidad
- Cierres
- Conciliaciones
- Control financiero
- Reportes
- Gestión de diferencias
- Soporte a auditoría

## 2. Tesorería

Responsabilidades:
- Posición de liquidez
- Gestión de fondos
- Seguimiento de saldos
- Proyección de flujos
- Operaciones financieras
- Monitoreo de límites internos

## 3. Conciliación

Objetivo: comprobar que los movimientos registrados en sistemas internos coinciden con las fuentes externas o sistemas de liquidación.

### Flujo
Fuente externa → extracción → normalización → matching → identificación de diferencias → investigación → ajuste autorizado → cierre.

### Tipos de diferencia
- Operación externa sin registro interno.
- Registro interno sin contraparte externa.
- Diferencia de monto.
- Diferencia de fecha.
- Diferencia de referencia.
- Duplicidad.
- Operación pendiente.
- Reverso no aplicado.

## 4. Matriz sintética de prioridad de conciliación

| Diferencia | Prioridad | Acción |
|---|---|---|
| Monto alto | P1/P2 | Escalación inmediata según umbral |
| Muchas operaciones afectadas | P1 | Command Center |
| Una operación sin impacto al cliente | P3 | Back Office |
| Diferencia contable de cierre | P2 | Finanzas + Contabilidad |
| Posible duplicidad | P2 | Operaciones + Riesgo |

## 5. Control de cierre

Antes del cierre diario:
- completar extracción;
- ejecutar matching;
- revisar excepciones;
- validar diferencias materiales;
- aprobar ajustes;
- documentar pendientes;
- generar evidencia;
- confirmar cierre.

## 6. Indicadores
- porcentaje conciliado;
- excepciones abiertas;
- antigüedad de excepciones;
- monto total pendiente;
- número de operaciones afectadas;
- tiempo medio de resolución.
